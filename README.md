# Astro ABM

**English** · [繁體中文](README.zh-Hant.md)

**A local-first AI market Worldline simulation platform.**

**Live website:** [qooqlo.com](https://qooqlo.com)

Astro ABM combines astronomical cycles, daily market data, macro and financial-stress context, and multiple AI agent groups to generate a market Worldline that can be inspected one day at a time.

It lets you explore:

- daily astronomy, market context, and data coverage
- simulated reactions from retail, leveraged, long-term, and macro agents
- agent events, pressure updates, simulated causal links, and next-day setup
- bilingual Worldlines generated by deterministic mock or OpenAI-compatible LLMs
- a 1926–2025 daily astronomy research layer and continuously maintained market data
- a Hong Kong Mark Six results archive and uniform-random entertainment Worldline explorer

> Worldlines are for association research and scenario rehearsal only. They are not causal proof, financial advice, or trading signals.

## Quick Start

Requires Docker, Python 3.11+, [uv](https://docs.astral.sh/uv/), and Node.js/npm.

```bash
git clone https://github.com/KiVixx/astro-abm.git
cd astro-abm

uv sync --extra dev
npm --prefix apps/web ci
make bootstrap
```

Start the API and Web app in separate terminals:

```bash
make api
```

```bash
make web
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000). Mock mode works without an LLM API key.

Create a demo Worldline:

```bash
make scenario-demo
```

Check data and service readiness:

```bash
make status
```

Build or refresh the ignored local Mark Six database:

```bash
make marksix-maintain
```

Then open `/marksix`. Number records cover 1976 onward; legacy 1976–1992 rows
have year/draw number but no reliable exact date, while complete dated records
start in 1993. Recent draws are refreshed from HKJC. Generated number Worldlines are uniform
random entertainment only: every valid combination has equal probability and
historical frequency does not predict future draws. Adults 18+ only.

The first `make bootstrap` builds the local database and 100-year core daily astronomy dataset, so it may take a while. Later updates are incremental through the maintenance container.
